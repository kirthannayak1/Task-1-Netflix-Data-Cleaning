# Data Cleaning and Preprocessing – Task 1

## Dataset

Netflix Movies and TV Shows

## Tool Used

Microsoft Excel

## Task Objective

The objective of this task was to clean and preprocess a raw Netflix dataset by identifying and correcting data quality issues and preparing the dataset for further analysis.

## Work Completed

The following data cleaning and validation steps were performed:

* Reviewed the dataset structure and checked that the column headers matched the data correctly.
* Checked all columns for missing or blank values.
* Identified missing values and handled them appropriately without removing valid records unnecessarily.
* Checked the dataset for duplicate records.
* Verified the `show_id` column and confirmed that all **8,808 IDs are unique**.
* Checked the `release_year` column for missing and unrealistic values.
* Confirmed that the `release_year` values range from **1925 to 2021**, with **0 missing values**.
* Checked the `type` column and verified that the values are consistent.
* Reviewed the `title` column for missing or incorrect values.
* Checked `director`, `cast`, `country`, `date_added`, `rating`, and `duration` columns for missing values and data consistency.
* Reviewed the dataset for inconsistent formats, incorrect entries, and other data quality issues.
* Saved the cleaned dataset separately from the original dataset.

## Result

The Netflix dataset was successfully cleaned and validated using Microsoft Excel. The dataset is now organized, consistent, and ready for further data analysis and visualization.
